# Release Notes

## v1.0.0

**Release tag:** `v1.0`

### Highlights

- Added a modular Python student-report application.
- Added student data and report entry-point modules.
- Added reusable score utilities for finding the highest score, lowest score, and average score.
- Added project setup and usage instructions.
- Added project dependencies through `requirements.txt`.

### Components

- `app.py` - application entry point and student report output
- `students.py` - student names and scores
- `utils.py` - score calculation helpers
- `README.md` - setup and usage documentation
- `requirements.txt` - Python dependencies
